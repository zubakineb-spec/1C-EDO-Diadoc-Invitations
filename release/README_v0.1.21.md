# v0.1.21 — фильтр нативных абонентов Диадок 2BM

Основа: v0.1.20-r1.

Изменения:
- массовая роуминговая пачка допускает только FnsParticipantId с префиксом `2BM`;
- `2AE`, `2AL` и любые другие операторские префиксы исключаются в dry-run;
- перед передачей в типовой помощник повторно выполняется проверка `2BM`;
- сбор данных для помощника также отбрасывает любой ИдЭДО, отличный от `2BM`;
- для `2AE` выводится отдельный статус: это не нативный абонент Диадок, требуется отдельная проверка прямой учетной записи 1С-ЭДО;
- сортировка, защита от дублей, статусы «уже отправлено / уже настроено» сохранены.

Важно:
Типовой помощник массовой отправки 1С-ЭДО сам проверяет известные учетные записи контрагента.
Перед фактической массовой отправкой требуется контрольный тест одной строки и проверка,
что в типовом помощнике выбран именно ИдЭДО `2BM...`.
