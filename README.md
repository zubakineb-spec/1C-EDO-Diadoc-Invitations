# 1C-EDO Diadoc Invitations

Внешняя обработка для массовой подготовки приглашений в 1С-ЭДО по контрагентам, с которыми уже установлен обмен в Контур.Диадок.

## Совместимость

- 1С:Бухгалтерия предприятия ПРОФ 3.0.202.14
- Контур.Диадок: фактически обнаруженная внутренняя версия модуля 4.68.0 (исходный файл пользователя: `Diadoc_4_53_3.epf`)
- 1С-ЭДО: используется штатный механизм `ПомощникМассовойОтправкиПриглашений`

## Версия

Текущая версия: `v0.1.0`.

## Архитектура

Обработка не хранит отдельный API-токен Диадока. Она использует уже подключённый модуль Контур.Диадок как слой авторизации и получения списка действующих партнёров (`IsMyCounteragent`), затем сопоставляет их с контрагентами 1С и передаёт выбранных контрагентов штатному механизму 1С-ЭДО.

## Безопасность

Версия 0.1.0 не выполняет необратимую массовую отправку автоматически: сначала формируется и проверяется список, затем открывается штатный помощник 1С-ЭДО.

## Состав

- `dist/РассылкаПриглашений1СЭДО_Диадок_BP_3.0.202.14_v0.1.0.epf` — готовая внешняя обработка.
- `src/` — исходники BSL из сборки.
- `docs/` — сведения по сборке и проверке.

## Статус проверки

Контейнер EPF прошёл статическую проверку и обратный разбор. Runtime-проверка непосредственно в 1С:Предприятии 8 на целевой базе должна быть выполнена отдельно перед промышленной рассылкой.
