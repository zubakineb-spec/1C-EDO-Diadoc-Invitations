# Рассылка приглашений 1С-ЭДО по контрагентам Контур.Диадок — v0.1.0

Целевая конфигурация: **1С:Бухгалтерия ПРОФ 3.0.202.14**.

## Назначение

Обработка получает из уже установленного модуля Контур.Диадок перечень контрагентов, с которыми у выбранной организации установлены партнерские отношения (`IsMyCounteragent`), использует штатное сопоставление Диадока со `Справочник.Контрагенты` и передает выбранных контрагентов в штатный помощник массовой отправки приглашений 1С-ЭДО.

## Интеграция с Диадок

Проверена по предоставленному файлу `Diadoc_4_53_3.epf`. Внутреннее имя обработки — `КонтурЭДО`, внутренний модуль сообщает версию **4.68.0**.

Используются экспортные/штатные интерфейсы модуля:

- `ИнициализироватьОбщийКонтекст()`;
- `Модуль_Ядро()`;
- `Контрагенты_ВыполнитьСинхронизациюОсновныхСтатусов()`;
- `Контрагенты_ГрупповоеСопоставлениеV2()`;
- `Контрагенты_СписокДляРазделаВашиКонтрагенты()`;
- статус `ПартнерскиеОтношения`, соответствующий `IsMyCounteragent`.

Токен/API-ключ Диадока обработка не копирует и не хранит. Она использует авторизацию уже установленного модуля.

## Первый запуск

1. Желательно один раз открыть штатный модуль Контур.Диадок в текущем сеансе 1С.
2. Открыть `РассылкаПриглашений1СЭДО_Диадок_BP_3.0.202.14_v0.1.0.epf`.
3. Выбрать организацию.
4. Нажать **Получить из Диадок**.
5. Если модуль `КонтурЭДО` еще не подключен в текущем сеансе, выбрать предоставленный файл Diadoc EPF. Он будет подключен через временное хранилище; учетные данные новая обработка не сохраняет.
6. Проверить таблицу кандидатов. Автоматически отмечаются только однозначно сопоставленные, действующие контрагенты.
7. Нажать **Передать в 1С-ЭДО**.
8. Проверить открывшийся штатный помощник `ПомощникМассовойОтправкиПриглашений` и только после проверки выполнить отправку штатной кнопкой 1С-ЭДО.

## Защита первого релиза

Версия 0.1.0 **не нажимает кнопку фактической массовой отправки автоматически**. Она формирует подтвержденный Диадоком список и передает его штатному помощнику 1С-ЭДО. Это сделано специально, чтобы первая промышленная проверка не могла создать неконтролируемую массовую рассылку.

## Обязательный runtime-gate

Наличие штатной формы массовых приглашений подтверждено для БП 3.0.202.14. Однако ее точное имя входного параметра со списком контрагентов не было доступно в имеющихся исходниках. Поэтому при первом запуске необходимо проверить, что помощник открылся **уже с нужным списком**.

Если помощник откроется без предварительно выбранных контрагентов, пришлите модуль формы `РегистрСведений.ПриглашенияКОбменуЭлектроннымиДокументами.Форма.ПомощникМассовойОтправкиПриглашений` или снимок результата первого запуска. После этого можно зафиксировать точный контракт и выпустить v0.1.1 без совместимых алиасов.
